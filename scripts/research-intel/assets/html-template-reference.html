Research Intel Template

论文单篇页的暖色专题模板

这个模板不是给模型抄内容，而是给它一个明确的气质锚点： 更像有叙事张力的研究专题页，而不是冷色研究简报、KPI 面板或机械堆卡片。

强 hero 标题 暖白 / 米色 / 浅金 叙事导语 + 概览信息带 证据卡嵌入正文
研究动机 方法结构 图表证据 评论
先给结论

首屏应该先把读者拉进问题与贡献，而不是一上来就做成数字面板。

为什么今天值得读

给出 1-2 句明确的阅读理由，让读者知道这篇论文在方法谱系里处于什么位置。

读完要带走什么

用结构化信息带承接关键信息，但别让信息带主导整页视觉。

研究动机

这一段适合先讲“问题为什么存在、为什么值得解决”，再铺开正文。

Warm Editorial Flow

先把读者带入论文冲突

好的单篇页不是把摘要拆成小卡片，而是先明确矛盾、限制与 stakes。 叙事开场要像专题报道：先建立 tension，再展开方法与证据。

信息带负责承接，不负责取代正文

可以有数据点、标签和速览块，但正文仍然要承担解释工作。 读者应当先感到“这篇论文值得读”，再进入细节。

核心想法与方法总览

模块形态要拉开：导语、并列卡、证据块、评论块各自承担不同阅读节奏。

可以有双栏，但别整页一套样式走到底

多栏适合讲方法链条、实验设计和评论对照；如果整页都只有同一种圆角卡片， 页面会滑向保守的“研究简报感”。

让 figure / table 真正服务叙事

关键图表不应只堆在结尾证据库里。至少把最重要的 2 处页面证据嵌回对应章节， 明确说清编号、页码、它支持了什么判断。

图表证据

证据卡应该看起来像正文的一部分，而不是额外附带的素材仓库。

Figure 1

用一张关键图解释整体框架、信息流或方法拆分。

Figure / Diagram Placeholder
写清编号、页码、作用与解读

Table 1

主结果表应和 baseline、指标、结论绑定，而不是只说“效果更好”。

Result Table Placeholder
突出关键数字与支持的论点

Appendix / Setup

如果附录给了 prompt、超参数或实现细节，要在实验设计处系统整理出来。

Appendix Evidence Placeholder
补复现关键信息，不要高层带过

评论

评论区应当有立场、有证据、有保留意见，不是礼貌复述作者贡献。

Reviewer Note

一个好的评论区通常会同时包含三类信息：

  • 这篇论文真正站住脚的贡献是什么。
  • 公开材料里哪些细节仍然没给够，导致严格复现仍有门槛。
  • 如果把它放进更大的方法谱系，它最像 prerequisite、core、contrast 还是 extension。

结尾收束区

最后收束时，适合分别给出“最重要的事实”“最重要的保留意见”“最值得带走的启发”。

最重要的事实

帮助读者快速回忆方法、结果和证据链最硬的部分。

最重要的保留意见

提醒哪些 claim 仍然依赖未公开细节、附录缺失或实验外推。

One More Thing

留下方法谱系、阅读路线或实现启发，让页面有真正的“作品收束感”。
