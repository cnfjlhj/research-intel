# 初始化画像说明

初始化脚本会写这几类文件：

- `research_brief.md`
  - 研究方向、当前目标、篇数范围、阅读偏好
- `seed_papers.jsonl`
  - 你已经读过或明确想锚定的论文
- `feedback.jsonl`
  - 正负反馈偏好
- `method_taxonomy.json`
  - 长期账本第一层结构
- `method_tree_notes.md`
  - 对账本整理逻辑的补充说明

如果你只是想快速体验，不想先手动回答问题，也可以直接运行：

```bash
npm run profile:example
```

这会把 `examples/profile/default/` 复制到真实运行目录，用于无副作用试跑和演示。
如果 `work/research-intel/profile/` 已经有你自己的画像文件，执行前请先备份。

## 推荐填写方式

### 研究方向

不要写太宽泛，例如：

- 不推荐：`AI`
- 推荐：`self-evolving agents 在 automated discovery 中的必要结构`

### 当前目标

目标尽量描述“这段时间为什么看论文”，例如：

- 为某个研究问题积累方法组件
- 为组会前补齐基线与方法谱系
- 为落地场景筛可迁移机制

### 正负信号

正信号回答：

- 什么样的论文会让我立刻点开
- 什么样的结构一看就值得收进方法账本

负信号回答：

- 哪类论文其实与当前阶段不匹配
- 哪类“看起来相关”但实际上浪费注意力

### 长期账本问题

建议按“问题”来分，而不是按“关键词桶”来分。

不推荐：

- memory
- agent
- benchmark

推荐：

- 为什么强 baseline 还不够
- 到底让什么在持续演化
- 什么反馈在真的驱动能力增长

## 初始化之后怎么迭代

最常编辑的就是：

- `work/research-intel/profile/research_brief.md`
- `work/research-intel/profile/feedback.jsonl`
- `work/research-intel/profile/seed_papers.jsonl`
- `work/research-intel/profile/method_tree_notes.md`

系统默认把这些文件当成长期记忆入口，而不是一次性表单。
